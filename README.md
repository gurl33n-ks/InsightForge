# 📊 InsightForge – Retail Intelligence Platform

## Overview

InsightForge is an end-to-end retail analytics platform built using Python, SQL, Power BI, and Streamlit.

The project analyzes over **100,000 e-commerce orders** from the Olist Brazilian E-Commerce dataset to uncover business insights related to sales, customers, products, delivery performance, payments, and customer satisfaction.

Rather than focusing only on data visualization, InsightForge follows a complete analytics workflow—from data understanding and cleaning to business intelligence dashboards and customer segmentation.

---

## Business Problem

Retail companies collect massive amounts of transactional data every day.

However, raw data alone does not answer critical business questions such as:

- Which product categories generate the most revenue?
- How are sales changing over time?
- Which customers are most valuable?
- Are delivery delays affecting customer satisfaction?
- Which payment methods are preferred?
- How can customer retention be improved?

InsightForge was built to answer these questions using data-driven analysis.

---

## Project Objectives

- Build a complete analytics pipeline
- Perform exploratory data analysis
- Create executive KPIs
- Analyze customer purchasing behaviour
- Segment customers using RFM Analysis
- Analyze product performance
- Evaluate delivery performance
- Analyze payment behaviour
- Build interactive Power BI dashboards
- Deploy a Streamlit analytics application
